# 🏋️ Gym Membership Management System

A modern and classy **Gym Membership Management System** built with **Python Flask, HTML, CSS, and JavaScript**.

This project provides a responsive web dashboard for managing gym members, searching member records, tracking membership fees, viewing statistics, and storing information in a CSV file.

---

## ✨ Features

- 👤 Add new gym members
- 🔎 Search members by name, ID, phone number, or membership type
- ✏️ Edit existing member information
- 🗑️ Delete member records
- 💰 Calculate total membership revenue
- 📊 View membership statistics
- 👨 Track male members
- 👩 Track female members
- 📈 Membership-type graphical overview
- 💵 Calculate average membership fee
- 💾 Automatic CSV data storage
- 🎨 Modern and responsive dashboard
- 🌐 Runs directly in Google Chrome
- 📱 Responsive layout for different screen sizes

---

## 🖥️ Dashboard

The system includes a clean dashboard showing:

- Total Members
- Total Revenue
- Male Members
- Female Members
- Average Membership Fee
- Membership Type Distribution
- Complete Member Table
